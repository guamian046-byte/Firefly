# 多用户博客平台

## 功能

- 邮箱和密码注册、登录以及 30 天安全会话。
- Markdown 草稿、投稿、审核、退回修改和公开发布。
- 管理员控制注册、投稿和强制审核总开关。
- 用户角色：普通用户、可信作者、审核员、管理员。
- 管理员可以启停账号和授予角色，但不能撤销自己的管理员身份。
- 用户 Markdown 会在服务端过滤危险 HTML 后显示。

## 管理员初始化

在服务器 `/etc/firefly.env` 中将 `ADMIN_EMAIL` 设置为站长邮箱。该邮箱注册时会自动获得
管理员角色。不要设置为公开或不受控制的邮箱。

```dotenv
DATABASE_URL=postgresql://firefly:随机强密码@127.0.0.1:5432/firefly
ADMIN_EMAIL=站长邮箱
```

环境文件应属于 root，权限设为 `600`。数据库只监听 `127.0.0.1`，不要在腾讯云安全组
开放 5432 端口。

## 数据备份

至少每天运行一次 `pg_dump`，将备份保存到站点目录之外，并定期把加密备份复制到另一处。
发布代码不会删除数据库中的用户或文章。
